Parking System:
Description:

This project simulates a smart parking system using Arduino. The system detects the presence of a vehicle and controls parking access automatically.

Features:
Vehicle detection
Parking status indication
Automatic access control
Real-time monitoring

Components Used:
Arduino Uno
Ultrasonic Sensor
LEDs
Jumper Wires
Breadboard

Working Principle:
The ultrasonic sensor measures the distance of an approaching vehicle. When a vehicle is detected within a predefined range, the system indicates parking availability and performs the required action.

Applications:
Smart parking management
Vehicle monitoring systems
Automation projects
