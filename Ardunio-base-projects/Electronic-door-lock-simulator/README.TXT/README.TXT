Electronic Door Lock Simulator:

Description:
This project simulates an electronic security door lock system using Arduino. Access is granted only when the correct button sequence is entered.

Features:
Password-based access control
Access granted and access denied indications
Multiple password attempts
Automatic lockout after repeated incorrect attempts

Components Used:
Arduino Uno
Push Buttons
LEDs
Buzzer
Resistors
Breadboard

Working Principle:
The user enters a predefined password sequence using buttons. If the entered sequence is correct, access is granted. If incorrect attempts exceed the limit, the system enters a temporary lockout mode.

Applications:
Electronic security systems
Access control systems
Arduino learning projects
