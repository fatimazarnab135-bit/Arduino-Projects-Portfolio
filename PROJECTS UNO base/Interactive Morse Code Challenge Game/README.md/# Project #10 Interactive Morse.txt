# Project #10: Interactive Morse Code Game

An interactive touchless gaming system designed using an **Arduino Uno** integrated with an HC-SR04 Ultrasonic Sensor, TTP223 Touch Sensor, tactile Push Button, dual LED indicators, and an active buzzer.

The project functions as an educational spatial telegraph simulator that decodes gesture dynamics into Morse code. 

---

## Features & Working Logic

* **Gesture Keying (Ultrasonic Sensor):** Placing a hand near the sensor (< 10 cm) acts as keying an input.
  * **Rapid wave (< 0.35s):** Decoded as a **Dot (.)**
  * **Hold ($\ge$ 0.35s):** Decoded as a **Dash (-)**
* **Challenge Generator (Push Button):** Steps through target challenge words (`SOS`, `HI`, `OK`, `CAT`, `GO`).
* **Space Delimiter (Touch Sensor):** Injects word delimiter spaces (` `) into the stream.
* **Automatic Verification:** Pausing for more than 2.5 seconds automatically submits and verifies the entered Morse sequence against the target word with audiovisual feedback via LEDs and Buzzer.

## Master Pin Mapping (Arduino Uno)

### 1. Power Infrastructure
| Component Line | Arduino Connection |
| :--- | :--- |
| Breadboard Red Line (+5V) | Arduino 5V |
| Breadboard Blue Line (GND) | Arduino GND |

### 2. Sensor & Actuator Connections

| Component | Pin / Terminal | Connected To | Notes / Function |
| :--- | :--- | :--- | :--- |
| **Touch Sensor (TTP223)** | VCC / GND / SIG | 5V / GND / **Pin 2** | Space Delimiter Key |
| **Ultrasonic Sensor (HC-SR04)** | VCC / GND | 5V / GND | Gesture Telegraph Key |
| | TRIG | **Pin 3** | Trigger Output |
| | ECHO | **Pin 4** | Echo Input |
| **Push Button** | Pin 1 / Pin 2 | **Pin 5** / GND | Challenge Generator (`INPUT_PULLUP`) |
| **Red LED** | Anode (+) / Cathode (-) | **Pin 8** (via 220Ω) / GND | Transmission / Error Indicator |
| **Green LED** | Anode (+) / Cathode (-) | **Pin 9** (via 220Ω) / GND | Success / Correct Entry Indicator |
| **Buzzer** | Positive (+) / Negative (-) | **Pin 10** / GND | Audio Feedback |

## How to Run

1. Open the project code file (`src/project_code.ino` or `.ino` file) in **Arduino IDE**.
2. Connect your **Arduino Uno** to your computer via USB.
3. Select board **Arduino Uno** and your correct **COM Port**.
4. Click **Upload**.
5. Open **Serial Monitor** at `9600` baud rate to view system prompts and decoded entries.
