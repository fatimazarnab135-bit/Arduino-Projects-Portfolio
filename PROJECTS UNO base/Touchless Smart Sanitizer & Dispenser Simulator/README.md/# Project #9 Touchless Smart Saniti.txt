# Project #9: Touchless Smart Sanitizer & Dispenser Simulator

An automated, contact-free sanitizer dispenser system designed using an **Arduino Uno** integrated with an HC-SR04 Ultrasonic Sensor, TTP223 Touch Sensor, dual LED indicators, and an active buzzer.

The system utilizes ultrasonic distance tracking to continuously monitor hand proximity. Upon hand detection (< 10 cm), it triggers a controlled single-dose dispense cycle while enforcing an anti-overflow safety lockout until the user's hand is removed.

---

## Features & Working Logic

* **Touchless Proximity Dispense (Ultrasonic Sensor):** Detects hand presence when placed within **< 10 cm**.
* **Anti-Overflow Safety Lockout:** Ensures only a single dose is dispensed per approach until the hand is fully removed.
* **Capacitive Maintenance Toggle (Touch Sensor):** Functions as a system lock/unlock switch for safe tank refilling and maintenance without triggering false dispenses.
* **Audiovisual Feedback:**
  * **Green LED:** Indicates System Ready state.
  * **Red LED + Buzzer:** Indicates Dispense Process active (simulating pump impulse).

## Master Pin Mapping (Arduino Uno)

### 1. Power Infrastructure
| Component Line | Arduino Connection |
| :--- | :--- |
| Breadboard Red Line (+) | Arduino 5V |
| Breadboard Blue Line (-) | Arduino GND |

### 2. Sensor & Actuator Connections

| Component | Pin / Terminal | Connected To | Notes / Function |
| :--- | :--- | :--- | :--- |
| **Touch Sensor (TTP223)** | VCC / GND / SIG | 5V / GND / **Pin 2** | System Lock / Refill Toggle |
| **Ultrasonic Sensor (HC-SR04)** | VCC / GND | 5V / GND | Hand Proximity Detection |
| | TRIG | **Pin 3** | Trigger Output |
| | ECHO | **Pin 4** | Echo Input |
| **Red LED** | Anode (+) / Cathode (-) | **Pin 8** (via 220Ω) / GND | Dispensing Indicator |
| **Green LED** | Anode (+) / Cathode (-) | **Pin 9** (via 220Ω) / GND | System Ready Indicator |
| **Active Buzzer** | Positive (+) / Negative (-) | **Pin 10** / GND | Pump Sound Simulation |

## How to Run

1. Open the project code file (`src/project_code.ino` or `.ino` file) in **Arduino IDE**.
2. Connect your **Arduino Uno** to your computer via USB.
3. Select board **Arduino Uno** and your correct **COM Port**.
4. Click **Upload**.
5. Open **Serial Monitor** at `9600` baud rate to view system states and dispensing events.
