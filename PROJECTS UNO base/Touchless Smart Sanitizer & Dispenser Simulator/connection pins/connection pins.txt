circuit wiring :
ARDUINO UNO PIN CONNECTIONS

1. POWER RAILS (BREADBOARD)
- Arduino 5V -> Breadboard Red Line (+)
- Arduino GND -> Breadboard Blue/Black Line (-)


2. ULTRASONIC SENSOR (HC-SR04)
- VCC  -> Breadboard (+)
- GND  -> Breadboard (-)
- TRIG -> Arduino Pin 3
- ECHO -> Arduino Pin 4


3. TOUCH SENSOR (TTP223) - Tank Lock/System Toggle
- VCC -> Breadboard (+)
- GND -> Breadboard (-)
- SIG -> Arduino Pin 2


4. RED LED (Dispensing Indicator)
- Long Leg (+) -> 220 Ohm Resistor -> Arduino Pin 8
- Short Leg (-) -> Breadboard (-)


5. GREEN LED (System Active / Ready Indicator)
- Long Leg (+) -> 220 Ohm Resistor -> Arduino Pin 9
- Short Leg (-) -> Breadboard (-)


6. ACTIVE BUZZER (Pump Motor Simulation Sound)
- Positive Pin (+) -> Arduino Pin 10
- Negative Pin (-) -> Breadboard (-)
